# Drone Simulation App

- 🚀 Live Demo: https://simulation-tan.vercel.app/
- 🔐 GitHub Repo: Private  
- 👤 Collaborator Added: prime@vecros.com

## Features
- Real-time drone path simulation
- CSV & manual coordinate entry
- Search & waypoint addition

## Tech Stack
- React + Leaflet
- Tailwind CSS
- Vercel for hosting
